
# MusicHub

MusicHub is a music library website developed using PHP and MySQL.

## Features
- View music records
- Add new music
- Edit music details
- Delete music records
- Search music
- AJAX search
- User registration and login
- Password hashing
- Session management
- CSRF protection
- Input validation and output escaping

## Technologies
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- AJAX
- GitHub

## Installation
1. Set up a MySQL database.
2. Create the required music and musichub_users tables.
3. Configure database credentials in db.php.
4. Upload the project to a PHP server.
5. Open the website in a browser.
